## 2. 矿石设计（6 普通 + 5 稀有）

无熔炼 → 每种矿石就是直接原料。设计原则：**每种稀有矿锚定一类产品；所有矿种在同一采矿场景都会出现，签名地区只上调宏观产量权重、不构成垄断产地**——玩家采矿本身是安全休闲的（§2.3），地区差异主要体现在宏观经济（NPC 产量与地区价格）。

### 2.1 普通矿（量大、低价）

| 矿石 | 材料域 | 主要分布 | 锚定用途 |
|---|---|---|---|
| 生铁陨矿 | 结构金属 | 全星域，边缘浅层极多 | 船体、装甲基底、枪管 |
| 铜脉砾矿 | 导体/线圈 | 全星域，小国走廊偏多 | 武器线圈、电路、电机 |
| 冰晶簇 | 挥发物/低温剂 | 外环与边缘冷区 | 推进剂、冷却剂、弹药化工 |
| 硅壳岩 | 电子基材 | 中立带（蓝砂协约周边） | 芯片、传感器、电子模块 |
| 碳泥团块 | 有机/聚合物 | 行星环带、农业区 | 聚合物、密封剂、纳米载体 |
| **冰矿** | **燃料** | 全星域，外环冷区更富 | 货舰燃料：公共物流消耗、走私召唤、玩家自用运力（见 §2.4） |

### 2.2 稀有矿（高价值；产地偏差只体现在宏观经济）

| 矿石 | 材料域 | 签名产地 | 锚定产品 |
|---|---|---|---|
| 辉钼晶 | 精密火控 | 赤岭共和国（火药桶）、边缘深空 | 火控芯片、长弓级 |
| 磁极稀土矿 | 电磁系统 | 卡戎工团（国有化！政治钩子） | 电子战（渡鸦级）、护盾 |
| 铱芯重矿 | 超重装甲 | 铁门侯国、边缘混战区 | 战列舰装甲、后勤舰 |
| 电浆凝矿 | 电浆储能 | 边缘深空（宏观产量最高区） | 电浆弹药、反应堆 |
| 活性纳米矿 | 纳米机械 | 静海深空（宏观产地；教区视为圣物——仅势力关系风味） | 纳米修复剂、T2 科技 |

### 2.3 采矿体验与稀有度

**采矿场景是绝对安全的休闲玩法**：没有危险机制，稀有度只意味着"少见"，不意味着"危险"。单一采矿场景内**全部 11 种矿都会出现**，区别只在出现权重。

场景权重（草案）：

| 矿石 | 场景出现权重 | 宏观经济产地偏差（只影响 NPC 产量与地区价格，不影响玩家采矿） |
|---|---|---|
| 生铁陨矿 | 很高 | 全星域 |
| 铜脉砾矿 | 高 | 小国走廊略偏 |
| 冰矿 | 高 | 外环冷区略偏 |
| 冰晶簇 | 中 | 外环略偏 |
| 碳泥团块 | 中 | 行星环带略偏 |
| 硅壳岩 | 中 | 中立带略偏 |
| 辉钼晶 | 低 | 赤岭略偏 |
| 磁极稀土矿 | 低 | 卡戎略偏 |
| 铱芯重矿 | 低 | 铁门略偏 |
| 电浆凝矿 | 很低 | 边缘深空略偏 |
| 活性纳米矿 | 很低 | 静海略偏 |

对 3D 场景的意义：安全+休闲定位下，挖矿的乐趣来自**发现稀有矿的惊喜**（特殊视觉/音效反馈）和**囤货换钱的收益感**，不来自风险压力。稀有度感知本身就是挖矿爽点的一部分。

### 2.4 燃料系统（冰矿的第二身份）

冰矿即燃料（与"无熔炼"一致：采出即可入库为燃料，草案 1 冰矿 = 1 单位燃料）。冰矿**不进任何制造 BOM**，它是运营消耗品——**物流的血液**。

| 消耗方 | 规则（2026-09-30 拍板） | 含义 |
|---|---|---|
| 公共货舰（NPC 物流流量） | **有燃料才来船**：本地燃料存量充足时，普通 NPC 货舰按固定节奏来访；每艘到港/离港消耗 N 单位本地燃料，并**按市价支付货币** | **燃料是出货闸门**：燃料断供=物流停摆，冰矿是新手第一优先级资源；物流越繁荣燃料收入越高 |
| 走私货舰召唤 | **主动召唤**，每次支付**高额燃料**（草案 = 20×公共货舰单次消耗，从本地燃料库存扣除）+ 货币费用 | 走私存在物理瓶颈：没有燃料库存就召唤不了，不能无脑刷 |

**玩家不操舰**（2026-09-30 拍板）：玩家没有驾驶舰船的能力，所有快递和运输均由 NPC 承担——出货吞吐完全由 燃料 × 泊位 × 舱容 决定，无玩家自用燃料消耗。

战略含义：**本地燃料短缺 → 公共物流减速/绕行**。燃料是能给星区经济放血的战略物资——不出一枪也能打"经济封锁"（垄断某星区燃料供应、掐公共物流），这是后期托拉斯级玩法的雏形。

相对单价指数（草案，1=基准）：生铁 1 / 冰矿 1.5 / 冰晶 2 / 铜脉 2 / 碳泥 2 / 硅壳 3 / 铱芯 10 / 辉钼 12 / 磁极稀土 12 / 电浆凝 15 / 活性纳米 20。

## 4. 许可证 → 逆向 → 原图蓝图 → T2

> **我的理解（请确认）**：生产以**许可证形式**进行（付许可费即可生产标准图纸的设备）；每完成一批许可证生产，该设备的**逆向研究等级**+1（边干边学）；逆向等级攒满，研究站产出**原图蓝图**；原图可继续研究：材料节省（ME）、建造加速（TE）、并最终解锁 **T2 科技**。

```
买许可证生产（付许可费=货币下水道）
        │  每批 +1 逆向等级（学习曲线）
        ▼
逆向等级满 ──研究站──→ 获得原图蓝图（从此免许可费）
        ▼
原图继续研究：ME（-材料%）· TE（-工期%）
        ▼
ME/TE 达标 + 研究站等级 ≥2 + 稀有矿投入 ──→ T2 科技解锁
```

### 4.1 许可证（次数制，EVE 蓝图副本式）

- **许可证带使用次数**：一张许可证授权生产 N 次（草案：小型产品 30 次/张、舰船 3 次/张），用完作废、需再购
- 来源：**来访货舰购买**（早期主要渠道，见 §5.3）/ 托拉斯授权 / 国家特许（帝国设备需好感度达标）
- 许可费：约为产品基准成本的 **15–25%**（重要货币 sink）
- 每次许可证生产仍 +1 逆向等级（§4.2）
- 政治属性：许可证供给本身就是势力关系的一部分——托拉斯可以通过"断授权"打击你

### 4.2 逆向研究

- 每完成 1 批许可证生产 → 该设备逆向等级 +1（小型产品满 10 级 / 舰船满 5 艘，草案）
- 研究站等级决定逆向并行槽数与速度
- **设计意图**：新手期是"给托拉斯打工交学费"，做大的路径是攒逆向把学费变成资产

### 4.3 原图蓝图研究

| 研究线 | 效果（每级） | 上限 |
|---|---|---|
| 材料研究 ME | 材料消耗 -2% | 10 级（-20%） |
| 建造研究 TE | 建造时间 -4% | 10 级（-40%） |

### 4.4 T2 科技（占位，暂不设计）

2026-09-30 拍板：**T2 暂不设计，只做占位**——UI 与数据结构预留 T2 字段与按钮（禁用态），具体规则留待后续版本。

原条件草案保留备查：原图 ME+TE 达标 + 研究站等级 ≥2 + 稀有矿投入（活性纳米矿 + 辉钼晶）→ 现有产品 T2 化（性能溢价、托拉斯级技术门槛；T2 仍是终局"第 21 席"需要的技术资产，只是现在不实现）。

## 5. 空间站建设（玩家基地）

空间站建在玩家矿区。**第一个建造的模块是物流机库，只用低级矿即可建成**——玩家从"挖矿"到"拥有可交易据点"之间只隔一次基础建设。

### 5.1 空间站组件（既是商品，又是制造原料）

空间站组件是矿石与建筑之间的制造层：**可以从来访货舰买、可以自己造、也可以卖给货舰**（EVE 式：组件既是贸易品又是建造材料），全部用矿石直接制造：

| 组件 | BOM（草案） | 用途 |
|---|---|---|
| 结构桁架 | 生铁 60 / 铜脉 20 | 所有模块的通用骨架 |
| 密封舱体 | 生铁 40 / 碳泥 30 | 机库、货柜的舱体 |
| 电子控制舱 | 硅壳 50 / 铜脉 30 / 辉钼 5 | 研究站、建造厂的控制核心 |
| 低温燃料舱 | 冰晶 40 / 冰矿 30 | 机库燃料储存与管理 |

### 5.2 模块建造配方（草案）

| 模块 | 建造消耗 | 备注 |
|---|---|---|
| **物流机库（首建）** | 生铁 200 / 结构桁架 2 / 密封舱体 1 | 全部低级矿链，新手第一座建筑 |
| 模块化货柜 | 结构桁架 1 / 密封舱体 1 | |
| 建造厂 | 生铁 300 / 结构桁架 2 / 电子控制舱 1 | |
| 研究站 | 硅壳 200 / 结构桁架 1 / 电子控制舱 2 | |

### 5.3 物流机库：泊位、船舱与来访货舰交易

**初级（1 级）机库只能停靠 1 艘工业运输舰**。交易是物理化的：手动卖出矿物和货物会**占用货舰的船舱**，船舱装满（或货舰资金用完）即离站，下一艘才进泊位。

所有货舰均为 NPC（玩家不操舰）：**普通货舰按固定节奏自动来访，前提是本地有燃料**（§2.4——燃料断供则不来船）；**走私货舰由玩家主动召唤**，支付更高燃料，仍受停靠开关（§5.4）约束。

点击机库可看到当前来访货舰列表，点击货舰进行交易：

- **玩家卖出**：原矿（直接卖矿石）、空间站组件、小型产品——装入货舰船舱（占用舱位），按货舰报价结算
- **玩家买入**：蓝图许可证（按次数，见 §4.1）、空间站组件、各种设备——从货舰货物清单中取出
- 货舰属性草案：隶属托拉斯/物流公司；**船舱尺寸**（本次最多带/收多少）；**货物清单**（卖什么：许可证、组件、设备）；**采购清单**（买什么+报价：矿石、组件、小型产品）；**有限资金**（收购额度，用完即走）

**工业运输舰船舱尺寸（草案，舱位 = 1 矿石单位）：**

| 型号 | 船舱容量 | 机库等级门槛 |
|---|---|---|
| 小型工业运输舰 | 400 舱位 | L1 |
| 标准工业运输舰 | 1,200 舱位 | L2 |
| 重型工业运输舰 | 4,000 舱位 | L3 |
| 托拉斯巨型货运舰 | 12,000 舱位 | L3 + 声望/事件 |

**出货效率是设计出来的瓶颈**：出货吞吐 = 泊位数 × 来船频率 × 单船舱容，装货时间由模块化货柜（每组 +25% 装货速度）压缩。算例（草案：每泊位每游戏日来船 1–2 艘）：L1 机库 = 1 泊位 × 小型舰 400 舱位 ≈ 日出货 400–800 舱位——新手采矿效率（草案 300–500 舱位/日）刚好被它卡住，**升级机库、加装货柜是最直接的"出货变快"反馈**，这正是机库作为首建模块的成长动力。

- 走私货舰：由玩家**主动召唤**（支付高额燃料，§2.4），占用泊位，受停靠开关控制（§5.4）

### 5.4 升级选项总览与模块机制（草案）

升级选项按四种形式组织：**等级制**（机库、研究站）、**叠加制**（建造厂、货柜）、**开关制**（走私停靠）、**功能解锁**（研究站项目树）。

| 模块 | 升级选项 | 形式 | 草案数值 |
|---|---|---|---|
| 物流机库 | 货舰泊位数量 | 等级 1/2/3 | 1 / 2 / 4 |
| 物流机库 | 可停靠货舰型号 | 随等级解锁 | L1 小型 / L2 标准 / L3 重型 |
| 物流机库 | 来访货舰档次 | 随等级提升 | 等级越高资金越足、稀有货越多 |
| 物流机库 | 走私货舰停靠 | 开关 | 开=暗市渠道+收入，代价=好感/评级/查抄风险 |
| 研究站 | 逆向/蓝图研究速度 | 等级 1/2/3 | 每级 +25% |
| 研究站 | 并行研究槽 | 等级 1/2/3 | 1 / 2 / 3 |
| 研究站 | T2 科技资格 | 功能解锁 | 需等级 ≥2 |
| 建造厂 | 并行生产线 | 叠加（上限 5 座） | 每座 +2 线 |
| 建造厂 | 建造加速 | 叠加（上限 5 座） | 每座 -4% 工期 |
| 建造厂 | 材料节省 | 叠加（上限 5 座） | 每座 -1% 材料 |
| 模块化货柜 | 装货速度 | 叠加（上限 4 组） | 每组 +25% |

模块机制明细：

| 模块 | 机制 | 玩法意义 |
|---|---|---|
