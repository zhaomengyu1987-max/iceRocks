# 世界设定 v0.1（《第二十一席》世界观圣经）

> 日期：2026-09-30。本文档全部为草案，数值与名称随时可改，但**势力结构**是设计骨架。
> 配套系统设计见 `design.md`。

---

## 1. 世界总览：三层结构

```
┌─────────────────────────────────────────────┐
│  两超对峙层                                  │
│  泛银河帝国 ←—— 时有时无的超大规模会战 ——→ 南方共同联合体 │
├─────────────────────────────────────────────┤
│  小国走廊层（7 国，两大强权之间的缓冲带与火药桶）      │
├─────────────────────────────────────────────┤
│  边缘星域层（开拓民/海盗武装犬牙交错，混战不停）      │
│  低端物资永远缺口 —— 玩家出生地                  │
└─────────────────────────────────────────────┘
```

- 约 20 个星际托拉斯横跨三层控制不同地区，下辖上千个下游供应商（统计层模拟）
- 玩家开局：在边缘星域拍下一片矿区的小公司

## 2. 泛银河帝国（简称：帝国）

- **政体**：帝制。皇室—贵族院—军务院三足，决策慢但体量大
- **经济**：国家兵工厂覆盖战争基线消耗 → **打不打得动不靠任何公司供货**。玩家和托拉斯的机会在峰值缺口、高端件、兵工厂不屑的杂活
- **采购文化**：政治准入制。采购局好感度决定合约资格，价格反而是次要的
- **市场特征**：需求匀速可预测；会战时溢价急单如山洪
- **对玩家的意义**：终点站。帝国特级特许是终局席位资格之一

## 3. 南方共同联合体（简称：南联）

- **政体**：议会联邦。采购预算、关税、动员等级全部经议会投票
- **经济**：兵工基础弱，吃市场供应深。公开招标、价低者得、履约信誉记录
- **市场特征**：价格敏感、竞争激烈、规则透明
- **对玩家的意义**：中期主场。议会是本作政治玩法的主战场——公司做大后，你投票改的是游戏规则本身

|---|---|---|---|
| 铁门侯国 | 军事侯国 | 帝国卫星国，常备军小而精 | 帝国准入的跳板，合约稳定 |

## 5. 边缘星域（玩家出生地）

**边缘武装集团（军需买家，详模拟）：**

| 势力 | 形态 | 特点 |
|---|---|---|
| 无锚者船队 | 流动掠夺者舰队联盟 | 边缘混战主力，低端军需最大买家 |
| 红砂同盟 | 矿业定居点自卫联盟 | 半政权化，买了货还想买"合法身份" |
| 铁壳帮 | 拆船港黑帮 | 废钢、二手件、人情生意 |

**边缘市场特征**：现金现货、无合约精神、价格波动剧烈。低端物资永远缺口的根本原因：利润薄、物流乱，托拉斯个个"理性"不屑弯腰——**这就是新手公司的生态位**。

## 8. 玩家起点

- 时间：两大强权紧张度处于中等偏低的"间歇期"，边缘照旧混战
- 地点：边缘星域某星区，刚拍下的一片矿区（含一台旧采矿平台）
- 身份：无名字小公司，无信誉、无雇员、无工厂
- 第一笔生意：把矿拉去最近的边缘现货市场——那里有现金，没有礼貌
