## 0. 已拍板的决策

| 决策点 | 结论 |
|---|---|
| 平台形态 | **单机 + NPC 世界**。模拟核心写成 headless 可跑的纯逻辑库，为将来搬上服务器留路径 |
| 玩家终点 | **成为第 21 个星际托拉斯**（新增席位或夺取现有席位） |
| 战争与玩家 | 基线军需由各国自有工业消化，"打不打得动"不取决于玩家；**会战级峰值需求外溢到市场，玩家的供货选择能压弯关键战役** |
| 表现形式 | **混合**：3D 矿区休闲采矿（爽点；玩家不操舰，运输全部 NPC）+ UI 经营（市场/合约/政治/战局图） |

## 1. 核心幻想

你不出一枪。这台庞大战争机器里，你只是刚买下一片矿区的无名小公司——但每场会战的弹药、每条战线的补给，都要经过你的报价单。**"这场战争是谁喂饱的"，就是玩家的权力来源。**

## 2. 核心循环

```
采矿 → 制造 → 销售（挂单/合约/委托）
        ↑                              ↓
矿区易主、需求转向 ← 战线推进/失地 ← 战争消耗军需
        ↑                              ↓
   政治投票（关税/采购/动员） ——→ 影响战争与市场规则
```

驱动这个循环运转的引擎是**战争消耗**：它是整个经济的需求来源和最大销毁渠道。没有战斗就没有消耗，没有消耗经济必然通胀停滞——战局系统因此不是看板，而是经济的心脏。

## 3. 三种政体 = 三门生意

同一个商品，在不同政体下是完全不同的买卖。这是世界设定的核心价值。

| 市场 | 政体/秩序 | 需求特征 | 玩家准入方式 | 政治玩法 |
|---|---|---|---|---|
| **泛银河帝国** | 帝制，国家兵工厂兜底基线 | 匀速、可预测的战备囤积；会战时峰值爆炸 | 平时靠政治准入（采购局/贵族院好感）；峰值缺口对所有人开放 | 无投票，做**关系**：好感度解锁合约等级 |
| **南方共同联合体** | 议会联邦，兵工弱、吃市场深 | 公开招标，价低者得但要履约信誉 | 竞标+信誉记录 | **议会投票**（本作政治玩法的主场） |
| **边缘星域** | 无秩序，开拓民武装混战 | 低端物资永远缺口，现金现货，波动巨大 | 无门槛，就是新手村 | 无。只有价格和胆量 |
| 小国走廊 | 各异（见 world.md） | 中等规模、偏好稳定合约 | 合约渠道 | 各国差异化的局部政治 |

由此天然形成玩家成长阶梯（空间+制度双重升级）：
**边缘现货 → 小国战线合约 → 南联招标+议会 → 帝国采购局关系户。**

## 4. 模拟架构：双层

上千个下游供应商**不逐个模拟**。

### 详模拟层（约 50 个实体，每 tick 决策）
- 2 个超级强权（帝国、南联）
- 7 个小国（见 world.md）
- **20 个星际托拉斯**——本作最重要的 NPC：雇主、竞争对手、市场庄家、玩家中期的吞并/打垮对象。每个有库存、产能、主营、靠山、行为性格
- 3 个边缘武装集团（军需买家）

### 统计层（不成为实体）
- 上千个下游供应商 = 按 **地区 × 行业** 聚合的"环境产能"数字
- 作用 1：吸收玩家扰动，防止价格被一人撬到暴走
- 作用 2：制造机会——某地区环境产能被战争摧毁 → 价格跳涨，玩家看得见、抓得住

## 5. 会战：需求冲击事件（游戏的心跳）

1. **紧张度积累**（数周）：强权战备采购单在市场上逐步放量——挂单深度可见
2. **战备期**（数日）：采购转为溢价急单，相关物资价格起飞
3. **会战爆发**（1–3 天）：巨量军需消耗；双方国家兵工厂只覆盖基线，**缺口以溢价急单形式涌入市场**；各方获得的供应量记为"供应分"
4. **战果结算**：战果 = 基础军力 + 供应分。**玩家把货卖给谁，就是在给哪边压弯天平**
5. **战后**：边境改写、重建潮、败方环境产能受损、长期补给缺口出现

两个关键机制：
- **市场即情报**：战前采购会在市场留下痕迹（EVE 玩家靠盯 Jita 挂单异动预判集结）。会读盘的玩家能在价格起飞前布好产能——这是本作最高级的涌现玩法，要做正式机制
- **供应可见性**：会战结算面板显示"你为本会战供应了 X，占 Y 阵营需求的 Z%"——让"我影响了战争"可感知，防止玩家觉得自己只是旁观者
- **公开 vs 私下**：公开采购记录全民可见（卖给敌国=政治后果）；**私下委托**是保密通道（走私敌国=高风险高利润）

## 6. 经济系统

### Faucet（货币注入）
- 国家采购付款（帝国采购局、南联招标、小国合约）
- 边缘现金现货买家
- 公共货舰燃料采购（物流流量带来的持续被动注入，玩家卖燃料即得）
- 政治补贴（议会投票产物）

### Sink（货币回收）
- 市场手续费与税
- 矿区租金/特许费
- 设备折旧、运输成本、雇员工资
- 公司扩张开销
- **战争消耗本身**（物资销毁是最大的下水道）

### 设计铁律
- **托拉斯是理性的**：不屑于伺候低利润市场——低端缺口是新手公司的生态位，不许 NPC 把它填平
- NPC 采购底价与市场价联动，防套利死水
- 每条商品链保留至少一个持续缺口，玩家永远有事可做

## 7. 政治系统

### MVP：南联议会
- **议题五类**：采购底价、关税税率、动员等级、战线优先、特许权审查
- **影响力来源**：供货履约记录、竞选捐款、游说开支
- 投票结果直接改真实数值，不产出风味文本

### 帝国（M3 之后）
- 采购局好感度体系：供货履约、政治献金、完成"脏活"（给边缘武装断供等）
- 好感度解锁合约等级 → 特许权 → 终局席位资格之一

### 边缘
- 无政治。信誉机制：卖过一次假货，全线买家压价

## 8. 玩家成长路线（对应终点"第 21 席"）

| 阶段 | 身份 | 解锁内容 | 对手/参照 |
|---|---|---|---|
| 0 | 拍荒者 | 1 片矿区、手工采矿、边缘现货 | — |
| 1 | 承包商 | 制造起步（小型产品）、雇员、小国合约 | **零点弹药**（边缘低端弹药现任霸主） |
| 2 | 供应商 | 多矿区+工厂、南联招标、议会影响力 | **人民货架**（薄利多销之王） |
| 3 | 军火商 | 会战峰值供货、帝国关系、私下委托网络 | 全体托拉斯 |
| 4 | 席位觊觎者 | 收购/打垮托拉斯、席位资格 | **第十港合作社**（最弱托拉斯=第一个夺席目标）、**深渊开采**（镜像对手） |

**终局条件（草案）**：满足其一——
- 新席路径：资产规模 + 供货份额 + 政治影响力三项达标，且获至少一个强权特级特许
- 夺席路径：目标托拉斯市场份额/产能被压到阈值以下，发起收购

## 9. MVP 范围

**MVP 只验证一句话：战争吃货 → 价格波动 → 有人囤货赚钱，这个循环好不好玩。**

- 地图：边缘 3–4 星区 + 1 条小国战线
- 商品：**11 种矿石（6 普通 + 5 稀有，不做熔炼、矿石直接进 BOM；冰矿=燃料）**；4 种小型产品与 4 型舰船（MVP 先上：小型武器、长弓级会战护卫舰）；空间站组件 4 种（商品+建造原料）；**物流机库=首个建造模块（低级矿），含来访货舰交易**（M1 引入）——详见 `manufacturing.md`。采矿为绝对安全的休闲玩法，单场景全矿出现、按稀有度分层
- 势力：1 个边缘武装买家 + 1 个小国合约渠道 + **零点弹药**（1 个有性格的托拉斯对手）
- 市场：1 个现货市场（边缘）+ 1 个合约渠道（小国）
- 政治系统、会战事件：**不在 MVP**（紧张度数值先显示）

## 10. 技术架构

- 引擎：**Godot 4.7.1，GDScript 为主**（约 50 代理的 tick 模拟对性能要求不高，迭代速度优先；热点再迁 C#）
- 三模块分层：
  - `sim/`：纯 GDScript 类库，**零 Node 依赖**，headless 可跑，tick 驱动，seeded RNG 保证可重放（调试用）
  - `client/`：UI——公司面板、市场、合约、议会、战局图
  - `mining3d/`：3D 采矿场景（休闲采矿交互 + 携带上限 + 返站结算；玩家不操舰，运输全 NPC；用户有推进器特效积累，采矿光束是表现力重点）
- 静态数据：`res://data/*.json`（goods / boms / factions / regions / trusts），改数值不改代码
- 市场：每 `(地区, 商品)` 一本订单簿；NPC 代理每日提交限价/市价单
- 存档：按游戏日 JSON 快照
- 模拟节奏：1 游戏日 = 数真实秒，市场撮合在 tick 内结算

## 11. 里程碑（承诺顺序，不承诺工期）

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| **M0 headless 纸面循环** | sim 核心 + 边缘市场 + 3 矿 + 2 级制造 + 零点弹药代理 + 1 条前线 tick + 价格图表 | 跑 30 游戏日：低端持续缺口存在、价格有可读波动、NPC 行为合理 |
| **M1 UI 垂直切片** | 公司面板/市场/战局图 v1/合约 v1（页面详设见 `ui.md`，DataProvider+Mock 可先于 sim 生成） | 阶段 0–1 完整可玩 |
| **M2 3D 矿区** | 采矿场景接入主循环 | 采矿体验是爽点不是负担 |
| **M3 政治+会战** | 南联议会 v1 + 会战事件管线 + 供应分结算 | 一场完整会战可被玩家的供货倾向左右 |
| **M4 世界全貌** | 20 托拉斯 + 7 小国 + 完整星图 + 终局 | 1.0 |
